# Radar Vision — SAR blog

A responsive, animated, single-page explainer about Synthetic Aperture Radar, its history, and the later use of subsurface radar sounders at Mars.

## Files
- `index.html` — complete site, including styling and animation JavaScript.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub Pages will provide the public site URL once its deployment completes.

## Notes
- The satellite, radar beam, surface and Mars graphics are original CSS illustrations, not actual SAR data products.
- The page respects the browser's reduced-motion preference.
- Main article copy and timeline are editable directly in `index.html`.
- The repository can remain private; availability of private-repository Pages hosting depends on the GitHub plan and repository settings.
